GiftUp — серверная часть
1) pip install -r requirements.txt
2) Запуск (на VPS с HTTPS, например за Caddy/nginx):
   BOT_TOKEN=токен_бота HOUSE_IDS=твой_tg_id ADMIN_KEY=длинный_секрет uvicorn app:app --host 0.0.0.0 --port 8000
3) В index.html впиши API_URL = "https://твой-домен" (этот же сервер отдаёт index.html на /).
4) Аккаунт-приёмник: Telegram → Настройки → Business → Чат-боты → выбери своего бота и включи права на подарки
   (просмотр подарков, передача и улучшение подарков).
5) Твои подарки для «склада» отправь на аккаунт-приёмник со своего аккаунта (его id указан в HOUSE_IDS) —
   они станут призами. Подарки всех остальных id зачисляются игрокам в инвентарь.
6) catalog.json: впиши английское название (key) каждого подарка — по нему сервер узнаёт входящие подарки.
   Если у коллекции несколько моделей (Durov's Cap), впиши model.

Настройки (переменные окружения)
  WITHDRAW_FEE=0.4   плата за вывод подарка, GRAM (по умолчанию 0.4; возвращается, если отправка не удалась)
  IP_LIMIT=90        запросов в минуту с одного IP
  TRUST_PROXY=1      включить, если сервер стоит за Caddy/nginx (иначе все запросы выглядят как один IP)
  TRANSFER_STARS=0   сколько звёзд платит аккаунт-приёмник Telegram'у за передачу подарка (если требуется)
Лимиты на пользователя: буст 20/мин, свободный кейс 5/мин, запрос состояния 40/мин, вывод 5/час.

Пополнение баланса (GRAM через TON Connect)
  DEPOSIT_ADDRESS=...  адрес ОТДЕЛЬНОГО кошелька, куда игроки шлют GRAM. Приватные ключи на сервере не нужны — он только читает входящие.
  PUBLIC_URL=https://твой-домен   для манифеста TON Connect (/tonconnect-manifest.json отдаётся сервером сам)
  TONCENTER_KEY=...    необязательно, ключ с toncenter.com
  MIN_DEPOSIT=0.1      минимальный перевод
Игрок подключает кошелёк кнопкой в профиле, жмёт «Пополнить» — сумма уходит на DEPOSIT_ADDRESS с комментарием gu<его id>,
сервер видит перевод и зачисляет баланс. Переводы без комментария или меньше минимума не зачисляются — они сохраняются в таблице deposits (credited=0) для ручного возврата.

Покупка за Telegram Stars (раздел «За звёзды»)
  Ничего дополнительно включать не нужно: сервер создаёт счёт в XTR (createInvoiceLink), сайт открывает его через Telegram (openInvoice),
  а бот принимает pre_checkout_query и successful_payment. Платёж зачисляется один раз; если коллекционный подарок закончился
  между счётом и оплатой, звёзды возвращаются автоматически (refundStarPayment).
  • Обычные подарки (nw:true в catalog.json): попадают в инвентарь, играют в апгрейде, вывести нельзя, призом быть не могут.
  • Коллекционные: берётся подарок со «склада» (HOUSE_IDS). Если склад пуст — счёт не выставляется.
  • Цена подарка в GRAM для расчёта шансов = звёзды × 0.0075 (поле price в catalog.json и STAR_RATE в index.html) — оценка, подстрой под курс.
